PitchModel

A retro, 1990s-desktop-styled MLB decision-support tool that forecasts the next pitch in real-time based on the live game situation.

Launch Application

About the Project

In high-stakes baseball, information is everything. PitchModel was developed to explore the patterns of MLB pitchers and provide fans or coaches with a "most likely" outcome for the next delivery based on the current game state.

Version 2.0 rebuilds the experience as a standalone web app with a live game-state workspace: set the pitcher, batter, count, outs, and runners, get a top-pitch prediction, then log what was actually thrown to track session accuracy in real time.

How It Works

  • Data Processing: Built around Statcast-driven pitch sequences, with a prediction service layer designed as a clean seam for a live FastAPI/KNN backend.
  • Logic Engine: Calculates probabilities from situational variables — count, outs, runners, and inning — and scores each logged pitch two ways: exact-match accuracy and "adjusted" accuracy that credits predictions within the same pitch family (Fastball, Breaking Ball, Offspeed).
  • Interface: Rebuilt in Next.js/React as an interactive, retro 1990s-desktop-styled workspace ("pitchmodel.exe") that updates predictions instantly as the user toggles game parameters.
